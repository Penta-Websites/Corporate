## 🏭 Company Overview
**ApexForge Industrial Corp.** is a Tier-1 advanced contract manufacturer and precision engineering provider specializing in 5-axis CNC simultaneous milling, Swiss turning, high-power fiber laser cutting, robotic welding, and DMLS additive manufacturing. With over 120,000 m² of plant infrastructure across Detroit (USA), Stuttgart (Germany), Singapore, and Monterrey (Mexico), ApexForge provides zero-defect component manufacturing to the aerospace, automotive EV, energy, and medical surgical robotics industries.

## 🚀 Key Features & Interactive Architecture
- **Theme-Grade Multi-Slide Hero**: High-impact rotating carousel with manual controls, pause-on-hover, key statistics bar, and fast-action CTAs.
- **Industry 4.0 Live Telemetry Strip**: Stochastic real-time monitoring simulating machine center OEE (99.4%), spindle velocities (18,240 RPM), and daily batch completions.
- **Instant Manufacturing Cost & RFQ Estimator**: Interactive calculator computing real-time part costs, volume discounts up to 64%, lead times, and setup amortizations based on material, process, tolerance, and surface finish.
- **CAD File Drag & Drop Simulation**: Client-side drag and drop parser supporting STEP, IGES, SLDPRT, STL, and DXF models with instant file feedback.
- **Interactive Industry Tabber**: Dedicated sectoral view for Aerospace & Defense, Automotive/EV, Energy/Turbines, and Medical Robotics.
- **Machinery Fleet Registry Table**: Comprehensive specifications for DMG MORI 5-axis centers, Mazak mill-turns, Hermle machines, Citizen Swiss lathes, and Zeiss CMM metrology.
- **Quality & Metrology Suite**: Detailed documentation of AS9100D, ISO 9001:2015, IATF 16949, ISO 13485, and NDT testing (PAUT, FPI, MPI, RT).
- **Responsive Architecture**: Fluid layout with sticky backdrop-filter navigation, off-canvas mobile menu, search overlay modal, back-to-top button, and toast notifications.
